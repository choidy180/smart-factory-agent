# 스마트 공정 설비 Agent

Next.js **15.3.2** App Router와 **styled-components**, **TypeScript(.tsx / .ts)** 기준으로 구성한 스마트 공정 설비 모니터링 대시보드입니다.

## 포함된 화면

- 실시간 알람 대응
- 문제 원인 분석
- 개선 Ideation
- 보전계획 수립
- 설정 · 알람 매니저

## 이번 수정 반영 내용

- `.jsx / .js` 파일을 `.tsx / .ts`로 전환
- `next: 15.3.2`, `react: ^19.0.0`, `react-dom: ^19.0.0` 기준으로 package 설정 변경
- Today’s Alarm 클릭 시 **선택된 알람 보고서가 즉시 교체**되도록 정리
- 선택된 알람의 제목/요약/핵심 정보가 상단 보고서 헤더에 크게 반영되도록 수정
- 각 섹션의 **검색 / 질문하기** 버튼 클릭 시 하단 검색 UI가 열리도록 정리
- 검색 UI는 **아래에서 상승**, 엔터 입력 시 **3초 로딩 후 자동 종료**
- 검색 시트는 `portal` 방식으로 렌더링되도록 변경해 UI 겹침 영향을 줄임
- 실시간 알람 대응 페이지는 `ssr: false` 동적 로딩으로 바꿔 클라이언트 상호작용 위주로 동작하도록 정리

### 2026.03.03 수정내용

1. 📋 알람 리스트 레이아웃 최적화 (AlarmListSection.tsx)
가독성 향상: 리스트 내 모든 텍스트 및 배지 사이즈를 시원하게 확대 (기본 18px 베이스).

공간 효율화 (데스크탑): 알람 리스트가 화면을 과도하게 차지하지 않도록 max-height: 200px로 고정하고 내부 상하 스크롤(overflow-y: auto) 적용.

테이블 헤더 정렬: 스크롤 생성 시 테이블 헤더와 본문의 칸 넓이가 어긋나는 문제를 해결하기 위해 헤더를 스크롤 영역 내부로 이동하고 상단 고정(position: sticky) 처리.

레이아웃 조정: '발생 시각' 컬럼의 너비를 데이터 길이에 맞게 140px에서 220px로 여유 있게 확장.

모바일 뷰 스와이프 적용: 모바일 화면에서는 세로로 길어지지 않도록 좌우 스크롤(가로 캐러셀, scroll-snap)이 가능한 카드 형태로 뷰 전환.

2. 🗺️ 지도 및 리포트 카드 시인성 강화 (MapReportCard.tsx, EquipmentMap.tsx)
컴포넌트 오버라이드: 외부 스타일드 컴포넌트를 오버라이드(!important)하여 패널 제목, 부제목, 버튼 등의 폰트 사이즈 대폭 확대.

비율 동기화: 글자 크기 증가에 맞춰 내부 아이콘(MapIcon, SearchIcon) 및 버튼 패딩, 범례(Legend) 간격 밸런스 조정.

지도 마커 확대: 설비 블록 내부 텍스트 및 맵 포인트 라벨 크기 상향(12px → 16px). 지도 마커(점)와 포커스 애니메이션(Pulse) 크기도 함께 키워 시각적 인지 능력 향상.

3. 📱 반응형 리포트 상세 레이아웃 (AlarmReportContent.tsx)
타이포그래피 스케일업: Hero 섹션의 주요 데이터(설비, 발생시각 등), 메타 텍스트, 칩(Chip) 컴포넌트들의 텍스트 크기 상향 및 버튼 터치 영역(높이/패딩) 확대.

모바일 접근성 개선 (CSS Order): 모바일 뷰(태블릿 이하)에서 사용자가 가장 먼저 확인해야 할 '조치 가이드' 카드가 최상단에 노출되도록 <GuideSlot> 컴포넌트를 분리하여 order: -1 속성 적용. (데스크탑 배열은 기존 위치 유지)

4. ✨ [New] AI 스마트 리포트 어시스턴트 (DesktopSidebar.tsx, ReportChatModal.tsx)
사이드바 신규 진입점: 데스크탑 사이드바 하단에 "📊 스마트 리포트 생성하기" 인터랙티브 버튼 추가.

챗봇형 리포트 모달 구현: 외부 차트 라이브러리(Chart.js 등) 의존성 없이, 순수 CSS 애니메이션 기반의 3가지 차트(수직 바, 수평 바, 비율/스택 바) 컴포넌트 자체 구현.

대화형 UX:

4가지 프리셋 질문(Prompt) 제공.

질문 클릭 시 타이핑 인디케이터(로딩 애니메이션) 노출 후 부드러운 스크롤 이동과 함께 리포트(텍스트+차트) 렌더링.

타입 안정성: 유니온 타입(Union Type) 에러 및 존재하지 않는 테마 색상(theme.colors.primary) 참조 에러 등 TypeScript 컴파일 이슈 완벽 해결 및 안전한 Hex Color 적용.
